# JJFZ 培训视频续播

适用于采用 JJFZ 前端的在线培训站点。脚本按课程中心的顺序读取必修课件和分集，自动处理播放器的断点续播与定时暂停。视频播完且页面显示完成回执后，队列进入下一段。静音偏好按站点保存，换视频后继续生效。

## 安装和使用

1. 下载 [篡改猴导入包](https://github.com/skitse/jjfz-course-player/releases/latest/download/jjfz-course-player.zip)。在 [篡改猴（Tampermonkey）](https://www.tampermonkey.net/) 的管理面板打开 **实用工具 → 导入**，选择 ZIP 文件。也可以 [下载脚本源码](https://github.com/skitse/jjfz-course-player/releases/latest/download/jjfz-course-player.user.js) 粘贴到编辑器。
2. 登录培训平台并打开课程中心。在脚本菜单中选择 **开始或继续全部必修视频**。
3. 需要静音时，选择 **静音播放（记住此站点）**。要取消静音，选择 **恢复声音（记住此站点）**。
4. **关闭此标签页的自动续播** 会暂停队列。同一标签页可以继续。课程目录更新后，可在课程中心选择 **重新读取必修目录并开始**。

如果安装过早期的「民大培训 · 视频续播」，先在篡改猴中停用旧脚本，避免两个脚本同时处理同一个播放器。

## 适用范围

- 脚本在 `/jjfz/lesson` 与 `/jjfz/play` 路径下识别课程卡片和播放器，首次自动播放由用户在该站点启动。学校域名、阶段编号、课程数量和课件链接都从当前站点读取。
- 队列只读取必修视频。网站播放器按自己的流程保存断点和学习进度。课程自测、考试和其他学习任务不属于视频队列。
- 请将播放页留在前台。网站没有显示完成回执时，队列会停在当前视频。已在网站完成的旧视频也可能出现在新生成的队列中。
- 队列保存在当前标签页的会话存储中。静音使用当前视频元素的原生静音属性。
- 中央民族大学实例是实测样本。其他学校需使用兼容的课程目录、分集和播放器结构。

## 本地测试

需要 Node.js 22 或更新版本。

```sh
npm ci
npm test
```

测试覆盖多站点目录、分页、静音偏好、完成回执、跨课件和跨课程切换，以及目录读取失败时保留原队列。
