# JJFZ 培训视频续播

JJFZ 指「积极分子」。脚本为兼容的在线培训站点生成必修视频队列，支持自动续播、切课和静音。

1. 在篡改猴的 **实用工具 → 导入** 中选择 ZIP。 [下载导入包](https://github.com/skitse/jjfz-course-player/releases/latest/download/jjfz-course-player.zip)
2. 登录培训站点并打开课程中心，从脚本菜单选择 **开始或继续全部必修视频**。
3. 需要静音时，从脚本菜单选择 **静音播放（记住此站点）**。

播放进度由培训站点记录。标签页重新可见后，脚本会尝试恢复播放。
