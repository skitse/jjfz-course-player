# 积极分子培训视频与题库助手

适用于采用兼容课程目录、播放器和自测页面的在线培训站点。先按课程中心的顺序播放全部必修视频，再由用户打开章节自测。脚本读取当前试卷、匹配内置题库，并填写可靠匹配的答案，每章最后由用户核对并交卷。

[Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/604583) · [GitHub 脚本源码](https://raw.githubusercontent.com/skitse/jjfz-course-player/main/jjfz-course-player.user.js)

## 安装和使用

在装有篡改猴（Tampermonkey）的浏览器中安装脚本。也可以在篡改猴管理面板中选择 **添加新脚本**，粘贴完整源码并保存。

### 第一步：完成视频学习

1. 登录培训平台并打开课程中心。在脚本菜单中选择 **开始或继续全部必修视频**。
2. 需要静音时，选择 **静音播放（记住此站点）**。要取消静音，选择 **恢复声音（记住此站点）**。
3. 视频播放结束且页面显示完成回执后，队列进入下一段，直到最后一门课的视频结束。
4. 视频全部完成后，回到课程中心，由你选择要做的章节自测。视频队列始终只处理视频，结束后会提示手动开始自测。

**关闭此标签页的自动续播** 会暂停队列，同一标签页可以继续。课程目录更新后，可在课程中心选择 **重新读取必修目录并开始**。已经打开某段必修视频时，可以选择 **从当前视频开始必修队列**，从这一段继续到目录末尾。

### 第二步：匹配题目，每章手动交卷

1. 在平台手动打开章节自测，右下角出现 **题库辅助** 面板。
2. 默认模式是 **填写可靠匹配的答案，每章手动交卷**。点击 **匹配本章题目**，查看可靠匹配和待核对数量。这一步只读取当前试卷。
3. 点击 **填写可靠答案（手动交卷）**。脚本逐题保存可靠匹配的答案，并重新读取题目确认保存结果。已有作答会保留。
4. 点击面板中的题号可跳转到对应题目。检查未匹配、近似题干、选项变化或答案冲突的题目，自己填写或修改，再核对网站答题卡。
5. 在网站上手动点击交卷。提交完成后，由你决定是否开始下一章。综合测试使用同一套匹配和填写流程。

也可以选择 **仅显示参考答案，自己填写并交卷**。此模式提供匹配结果和参考答案，填写按钮停用。

脚本不会调用交卷接口，也不会自动开始下一份试卷。平台自己的倒计时和超时交卷仍然生效，请在倒计时结束前完成核对。

## 题库和匹配规则

内置 **350 道题**，来自 360 条已提交答卷的批改记录，包含单选、多选、判断和填空。重复题已去重，答案以平台回顾页为准。题库随脚本打包，使用时无需连接外部题库服务。

匹配按题干、题型和完整选项集合进行。脚本根据答案文字映射当前选项，适配选项顺序变化。全角半角、空格、常见标点和空白括号会统一处理，数字、否定词和数学符号保留。

| 匹配结果 | 脚本行为 |
| --- | --- |
| 题干、题型、选项集合一致，答案唯一 | 可以填写，并核对网站保存结果 |
| 题干近似 | 显示相近题干和参考答案，由用户判断 |
| 选项发生变化 | 提示人工核对，保留当前作答 |
| 同一道题存在不同答案 | 提示答案冲突，保留当前作答 |
| 新题或未匹配 | 标出题号，由用户完成 |
| 用户已有作答，或匹配后修改过答案 | 保留用户作答 |
| 网络错误、题目标识变化、保存结果未确认 | 停止本次填写，显示已确认保存的数量 |

题库覆盖的是收集到的题目。课程更新或随机组卷可能出现新题，面板会把这些题目列为待处理。近似匹配始终只用于提供参考。

## 自定义站点地址

1. 在篡改猴管理面板打开本脚本的 **设置 → 用户匹配**，添加要使用的站点地址规则。规则需要覆盖课程中心、课件列表、视频播放页和自测页。也可以把不想启用的页面加入 **用户排除**。
2. 打开站点后，在脚本菜单选择 **配置本站页面地址**，每行一个，依次填入课程中心、课件列表、视频播放页。支持完整的本站网址或以 `/` 开头的路径，留空恢复默认。
3. 自测地址也不同时，在后面再加两行：章节自测页、综合测试页，共五行。填写实际答题页的路径；题目读取和答案保存接口须与对应页面采用兼容结构。

默认支持 `/jjfz/lesson`、`/jjfz/play`、`/jjfz/lesson/exam` 和 `/jjfz/exam_center/end_exam`。阶段编号由当前网址的 `stg` 读取，课程数量和视频链接从站点目录读取。修改地址用于适配兼容站点，页面结构和接口协议仍需兼容。

## 视频播放说明

- 队列只读取必修视频，播放器按网站自己的流程保存断点和学习进度。
- 自动续播开启后，切到其他标签页也会继续播放和切课。播放器中的手动暂停和网站其他弹窗仍然有效。浏览器冻结或丢弃标签页时，播放会中断。
- 视频长时间卡在同一位置时会重新载入，继续使用网站保存的断点。连续重载最多两次。
- 网站没有显示完成回执时，队列停在当前视频。已完成的旧视频也可能出现在新生成的队列中。
- 队列保存在当前标签页的会话存储中。静音偏好按站点保存，使用视频元素的原生静音属性，换视频后继续生效。

## 开发和测试

需要 Node.js 22 或更新版本。

```sh
npm ci
npm run build
npm test
npm run check
```

`src/course-player.js` 负责视频队列，`src/question-core.js` 负责题目解析与匹配，`src/question-assistant.js` 负责当前试卷的交互和保存确认。题库保存在 `data/questions.json`，只包含题型、题干、选项和答案文字。修改源码或题库后，运行构建命令生成根目录的安装脚本。

测试覆盖全部题库的选项重排、题干规范化、近似题与答案冲突、已有作答保护、保存确认、网络失败停止，以及原有的多站点视频目录、静音、后台续播、完成回执和跨课程切换。

本地浏览器模拟页可用以下命令启动，终端会输出访问地址：

```sh
node scripts/browser-fixture.cjs
```
